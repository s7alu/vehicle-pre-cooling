# Deployment environments

| Environment | Branch        | URL                                                        |
| ----------- | ------------- | ---------------------------------------------------------- |
| Production  | `main`        | https://vehicle-pre-cooling.vercel.app                     |
| Staging     | `staging`     | https://vehicle-pre-cooling-git-staging-sahal25.vercel.app |
| Preview     | any PR branch | Generated per-PR by Vercel, linked on the PR               |

Hosted on Vercel, project `sahal25/vehicle-pre-cooling`. Non-production deployments (staging, preview) are protected by Vercel Authentication by default — viewing them requires being logged into the Vercel account that owns the project.
